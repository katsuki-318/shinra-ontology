セマンティックレイヤーで整理する
公開情報をもとに、世の中に存在するあらゆる事物・現象・概念を RDF/OWL オントロジーとして外在化する。完璧な網羅ではなく、 自分の脳内モデルを段階的に明示化するプロセス。

01 目的・スコープ・非ゴール
目的
脳内モデルの外在化
「世の中にある事物・現象・概念のすべて」を公開情報を根拠として推論可能な RDF/OWL オントロジーとして整理する。知的探索のツールとして使う。
スコープ
あらゆる存在領域
時空・物理・生物・人間・社会・文化・技術・抽象概念。日本語を主ラベル、英語を必須サブラベルとして両方記述。根拠は Wikipedia / Wikidata / 政府統計 / 学術論文等。
非ゴール
やらないこと
Wikidata の全データ取り込みは目指さない。ビジネス用途・商用配布を目的としない。特定ドメインに閉じた専門オントロジーにしない。
設計哲学
整合性 > 網羅性
完璧より進化可能性。抽象→具体ではなく具体→抽象の順でドメインを積む。インスタンス 3 個入れたら Done をルールとし、完璧主義を防ぐ。
02 上位オントロジー：BFO 2020

BFO 2020 (ISO/IEC 21838-2:2021) を採用。37 クラスからなるミニマルな骨格に独自の中位クラス・ドメインクラスを積み上げる。採用根拠：国際標準・37 クラスのミニマル設計・650+ プロジェクトでの採用実績・継続物/生起物の二項分割が直感的。
