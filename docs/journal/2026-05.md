## 悩んだこと・保留にしたこと

### ConceptualEntity の位置づけ
「概念」は BFO の `generically dependent continuant` に置いたが、これは BFO の哲学的立場（観念論でなく実在論）と微妙に緊張する。BFO は「概念は心的表象であり、generically dependent continuant として扱える」という立場を取るが、プラトン的イデアを念頭に置くと `independent continuant` にしたくなる衝動がある。

**結論**: BFO 公式の立場に従い `generically dependent continuant` の下に置く。再解釈しない。

### SpatiotemporalRegion を今回作るか
BFO には `bfo:0000011 (spatiotemporal region)` が存在する。今月は時間領域のみ `shinra:TemporalRegion` として定義し、時空間領域は Phase 3（時空ドメイン）で扱う。

## 3ヶ月後の自分へ

このプロジェクトを続けているなら、以下を思い出してほしい:

1. **BFO を信じる** — 「なぜ BFO はこう分類するのか」という哲学的議論に深入りしない。BFO 公式が言っている通りに従う。
2. **インスタンス3個でDone** — クラスを完璧に定義しようとしない。典型例3個入れたら次へ進む。
3. **Wikidata は参照するが飲まれない** — クラス定義後は Wikidata で対応例を3つ確認して終わり。Wikidata の階層構造を自分のオントロジーに取り込まない。
4. **ツールは凍結** — Phase 1 終了時点でツールチェーンは固定。新しいツールに浮気しない。
5. **月次リリースを守る** — 完璧でなくても毎月タグを打つ。それが唯一のリズム。
