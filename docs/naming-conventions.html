01基本原則
  • 1英語名（ASCII）が正式 ID — URI を構成する識別子は必ず英語 ASCII で書く
  • 2日本語ラベルは必須 — rdfs:label@ja をすべてのクラス・プロパティに付ける
  • 3英語ラベルも必須 — rdfs:label@en をすべてに付ける（LOD 接続・国際公開のため）
  • 4コメントは両言語 — rdfs:comment@ja と rdfs:comment@en を両方記述
  • 5連番 ID を必ず付ける — skos:notation "SHINRA_0000001" でリネーム耐性を確保
02クラス（Class）

命名形式: PascalCase + 単数形名詞

MaterialEntity InformationContentEntity NaturalProcess AstronomicalBody

禁止: Persons（複数形）/ InfoEnt（略語）/ 物体（日本語URI）

クラス定義テンプレート:

shinra:MaterialEntity a owl:Class ; rdfs:subClassOf bfo:0000030 ; # bfo:Object rdfs:label "物質的実体"@ja ; rdfs:label "Material Entity"@en ; skos:altLabel "物理的対象"@ja ; rdfs:comment "空間的に位置を持ち、独立して存在する物質的なもの。"@ja ; rdfs:comment "A material entity that exists independently and has spatial location."@en ; skos:notation "SHINRA_0000001" ; dcterms:created "2026-05-12"^^xsd:date .
03プロパティ（Property）

命名形式: lowerCamelCase + 動詞句（ObjectProperty）/ 名詞句（DataProperty）

例種別読み
participatesInObjectProperty〜に参与する
hasPartObjectProperty〜を部分として持つ
aboutnessObjectProperty〜について（情報→対象）
bearerOfObjectProperty〜を担持する
birthDateDataProperty誕生日

BFO 2020 にすでに定義されているプロパティは 再定義しない。独自プロパティは BFO に存在しない概念の場合のみ定義する。

BFO プロパティ利用場面
bfo:participates-in継続物 → 過程
bfo:has-participant過程 → 継続物
bfo:has-part部分関係
bfo:located-in場所関係
bfo:bearer-of担持関係
bfo:inheres-in内在関係
04インスタンス（Individual）

命名形式: 英語小文字 slug + ハイフン + UUID 短縮（6文字）

shinra-data:tokyo-station-a3f4c9 shinra-data:natsume-soseki-b2e7d1 shinra-data:pacific-ocean-c8d3e2

slug は人間可読性のため。UUID 部分がリネームへの耐性を担保する。固有名詞はローマ字または英訳を使う。

05ラベル・コメントの記述規則
述語言語書き方
rdfs:label@ja（主）漢字・ひらがな・カタカナ混在OK。最も自然な呼び方
rdfs:label@en（必須）頭文字大文字のタイトルケース
skos:altLabel@ja / @en同義語・口語・別表記。多いほど検索精度が上がる
rdfs:comment@ja / @en 両方1〜3文で「〜とは〜である」形式の定義文

BFO の公式定義がある場合は参照し、独自解釈を上乗せしない。

06連番 ID（skos:notation）
種別プレフィックス例
クラスSHINRA_ + 7桁SHINRA_0000001
ObjectPropertySHINRA_P + 6桁SHINRA_P000001
DataPropertySHINRA_D + 6桁SHINRA_D000001

連番 ID により、URI の名称を変更した場合でも同一概念を追跡できる。ROBOT report で月次に重複を確認する。一度付けた連番 ID は変更しない。

07外部 ID マッピング
述語使用条件
owl:sameAsインスタンスレベルのみ（クラスには使わない）
skos:exactMatch概念が完全に等価
skos:closeMatch概念が近いが微妙にずれる
skos:broadMatchより広い上位概念にマッピング
shinra:MaterialEntity skos:exactMatch <http://www.wikidata.org/entity/Q35120> ; skos:closeMatch <https://schema.org/Thing> . shinra-data:tokyo-station-a3f4c9 owl:sameAs <http://www.wikidata.org/entity/Q941320> .

クラスへの owl:equivalentClass は推論爆発の原因になるため 禁止。
